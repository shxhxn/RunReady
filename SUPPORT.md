# RunReady support

## Project not running? Send me the error.

Use the [RunReady error report form](https://github.com/shxhxn/RunReady/issues/new?template=bug_report.yml). You can report a failing command, a missing run command, a dependency problem, or an app that did not open.

You do not need to know the correct command, edit a repository file, or create a pull request. Sign in to GitHub, fill out the form, and click **Submit new issue**. Each report gets its own page where we can discuss the problem and track a fix.

### What to send

1. **The complete command RunReady prepared.** Copy it from the terminal or clipboard. If no command appeared, say so.
2. **The exact error as text.** Select the error and the surrounding lines in the VS Code terminal, then use the terminal's **Copy** action. Paste the text into the error field. If RunReady showed a notification instead, copy that message.
3. **Your project setup.** Name the language or framework, if known, and list relevant files and folders such as `package.json`, `requirements.txt`, `backend/app/main.py`, or `dashboard.py`.
4. **Your environment.** Include the operating system, terminal shell, and RunReady version. The version is visible in **Extensions > RunReady**.

The form preserves commands and errors as code blocks. Screenshots and **View > Output > RunReady** logs are optional; pasted error text is easier to investigate. A working command is helpful if you know one, but it is not required.

Reports are public. Remove API keys, passwords, tokens, `.env` contents, private source code, and sensitive paths or data before submitting. A small public example is enough; do not upload your whole private project.

### After submitting

Keep additional information in the same issue. I may ask for a small example or another log to reproduce the problem. When a fix is available, the issue can link to the relevant change or release. Some errors come from a project's own code, configuration, or missing system tools, so a report helps identify whether RunReady needs a fix or the project needs a different setup.

## Feedback and requests

Have an idea, want another project type supported, or want to share what worked? Use the [feedback form](https://github.com/shxhxn/RunReady/issues/new?template=feedback.yml).

For a rating or public review, open [RunReady on the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=shxhxn.runready) and use its reviews section. Use the error form for troubleshooting.

[Browse existing reports and feedback](https://github.com/shxhxn/RunReady/issues) before opening a duplicate.
